🔷 LOGICAL INSTRUCTIONS
Register-to-Register Logical Operations
NOT 00001 rd rs1 X 0000 X not rd, rs1 Bitwise NOT: rd = ~rs1
AND 00001 rd rs1 rs2 0001 X and rd, rs1, rs2 Bitwise AND: rd = rs1 & rs2
OR 00001 rd rs1 rs2 0010 X or rd, rs1, rs2 Bitwise OR: rd = rs1 | rs2
XOR 00001 rd rs1 rs2 0011 X xor rd, rs1, rs2 Bitwise XOR: rd = rs1 ^ rs2
SHL 00001 rd rs1 rs2 1001 X shl rd, rs1, rs2 Shift left logical: rd = rs1 << (rs2 % 32)
SHR 00001 rd rs1 rs2 1010 X shr rd, rs1, rs2 Shift right logical: rd = rs1 >> (rs2 % 32)
ROTL 00001 rd rs1 rs2 1101 X rotl rd, rs1, rs2 Rotate left: rd = (rs1 << shamt) | (rs1 >> (32-shamt))
ROTR 00001 rd rs1 rs2 1110 X rotr rd, rs1, rs2 Rotate right: rd = (rs1 >> shamt) | (rs1 << (32-shamt))
Immediate Logical Operations
ANDI 00010 rd rs1 imm 0001 imm andi rd, rs1, imm Bitwise AND with immediate (zero-extended): rd = rs1 & imm
ORI 00010 rd rs1 imm 0010 imm ori rd, rs1, imm Bitwise OR with immediate (zero-extended): rd = rs1 | imm
XORI 00010 rd rs1 imm 0011 imm xori rd, rs1, imm Bitwise XOR with immediate (zero-extended): rd = rs1 ^ imm
SLI 00010 rd rs1 imm 1001 imm sli rd, rs1, imm Shift left immediate (0-31): rd = rs1 << imm
SRI 00010 rd rs1 imm 1010 imm sri rd, rs1, imm Shift right logical immediate (0-31): rd = rs1 >> imm
➕ FMA/MAC
FMA 10000 rd rs1 rs2 0001 rs3 fma rd, rs1, rs2, rs3
MAC 10000 rd rs1 rs2 0010 00000000 mac rd, rs1, rs2
➕ ARITHMETIC INSTRUCTIONS
Register Arithmetic Operations
ADD 00011 rd rs1 rs2 0000 X add rd, rs1, rs2 Integer addition: rd = rs1 + rs2
SUB 00011 rd rs1 rs2 0001 X sub rd, rs1, rs2 Integer subtraction: rd = rs1 - rs2
MUL 00011 rd rs1 rs2 0010 X mul rd, rs1, rs2 Signed 32-bit multiplication (lower 32 bits): rd = (rs1 * rs2) & 0xFFFFFFFF
DIV 00011 rd rs1 rs2 0011 X div rd, rs1, rs2 Signed integer division: rd = rs1 / rs2
Immediate Arithmetic Operations
NOP -- (addi) 00011 rx0 rx0 0000 1000 0000 nop --> (addi rx0, rx0, 0x0) no operation
ADDI 00011 rd rs1 imm 1000 imm addi rd, rs1, imm Add immediate (sign-extended): rd = rs1 + imm
SUBI 00011 rd rs1 imm 1001 imm subi rd, rs1, imm Subtract immediate: rd = rs1 - imm
💾 MEMORY & IMMEDIATE INSTRUCTIONS
Load Operations
LD 00100 rd rs1 imm 0001 imm ld rd, rs1, offset Load word from memory: rd = MEM[rs1 + offset]
LI 00100 rd X imm 0010 imm li rd, imm Load immediate (sign-extended 12-bit): rd = imm
MOV 00100 rd rs1 X 0100 X mov rd, rs1 Move register: rd = rs1
Store Operations
STORE 00110 X rs1 rs2 0001 offset st rs2, rs1, offset Store word to memory: MEM[rs1 + offset] = rs2
🎯 BRANCH & CONTROL FLOW INSTRUCTIONS
Branch Operations
BZ 00101 rd X X 0001 X bz rd Branch to address in register: PC = rd if above statement result in flag Z = 1
BNZ 00101 rd X X 0010 X bnz rd Branch to address in register: PC = rd if above statement result in flag Z = 0
JUMP 00101 X X imm 0100 imm j imm jumps to the address = imm
R-to-R Compare Operations
CMP_LT 00111 X rs1 rs2 0001 X clt rs1, rs2 Set condition flag if rs1 < rs2 (signed comparison)
CMP_LT 00111 X rs1 rs2 0010 X ceq rs1, rs2 Set condition flag if rs1 == rs2
Immediate Compare Operations
CMP_LT_IMM 00111 X rs1 imm 1001 imm clti rs1, imm Set condition flag if rs1 < imm (signed comparison)
CMP_EQ_IMM 00111 X rs1 imm 1010 imm ceqi rs1, imm Set condition flag if rs1 == imm
⚙️ SYSTEM & CONTROL INSTRUCTIONS
Mask Operations
MASKRST 01000 X X X 0001 X maskrst Reset SIMT execution mask (all threads active)
MASK 01000 X X imm 0010 imm mask val Set SIMT execution mask to immediate value
Conditional Move Operation
CMOV 01001 rd rs1 rs2 0001 mask cmov rd, rs1, rs2, mask cmov r1, r2, 0, (r2 > 0) --> rd = (mask ? rs1 : rs2)
Lane ID Operation
GET_LANEID 01001 rd X X 0010 X glid rd fetches the lane ID into the register rd.
Atomic Add Operation
atomadd 01001 X rs1 addr 0100 addr atomadd [addr], rs1
Reduce Add Operation
redadd 01001 rd rs1 X 1000 X redadd rd, rs1
Exit and End Operation
EXIT 11111 X X X 0001 X exit Terminate current thread/warp execution
END 11111 X X X 0010 X end End of kernel / program halt
